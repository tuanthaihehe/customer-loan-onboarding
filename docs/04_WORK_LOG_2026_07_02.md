## 7. Chuẩn hóa enum cho trạng thái tài sản và các field enum-like trong DB

### Bối cảnh

Khi kiểm tra API:

```http
POST /api/v1/assets/lookup
```

logic cũ đang dùng string trực tiếp:

```java
"AVAILABLE".equals(asset.getStatus())
```

Cách này khiến mọi trạng thái khác `AVAILABLE` đều bị chặn, bao gồm cả:

```text
RELEASED
SETTLED
```

Trong khi theo nghiệp vụ hiện tại cần hiểu rõ:

```text
PLEDGED  -> tài sản đang cầm cố, không được gắn vào hồ sơ vay mới
RELEASED -> tài sản đã giải chấp, có thể dùng lại
SETTLED  -> khoản vay cũ đã tất toán, có thể dùng lại
AVAILABLE -> tài sản đang khả dụng, có thể dùng
```

### Đối chiếu thiết kế DB

Đã rà trong `database/migrations` và `resources/db/migration`.

DB hiện không dùng PostgreSQL `CREATE TYPE enum`, mà dùng `VARCHAR + CHECK constraint`.

Các field enum-like đã xác định:

```text
asset.status
customer.status
customer.gender
customer.marital_status
loan_application_reference_person.relationship_type
```

Các phần như:

```text
loan_purpose
loan_term
score_grade
```

hiện là catalog table, không nên convert thành enum cứng trong Java.

### Enum đã thêm

```text
AssetStatus
CustomerStatus
Gender
MaritalStatus
ReferenceRelationshipType
```

### Entity đã cập nhật

`Asset.status` đổi từ `String` sang:

```java
@Enumerated(EnumType.STRING)
private AssetStatus status;
```

`Customer.status` đổi từ `String` sang:

```java
@Enumerated(EnumType.STRING)
private CustomerStatus status;
```

`Customer.gender` đổi sang:

```java
@Enumerated(EnumType.STRING)
private Gender gender;
```

`Customer.maritalStatus` đổi sang:

```java
@Enumerated(EnumType.STRING)
private MaritalStatus maritalStatus;
```

`LoanApplicationReferencePerson.relationshipType` đổi sang:

```java
@Enumerated(EnumType.STRING)
private ReferenceRelationshipType relationshipType;
```

### Chuẩn hóa logic lookup tài sản

File đã sửa:

```text
backend/loan-onboarding/src/main/java/com/f88/loanonboarding/service/impl/AssetServiceImpl.java
```

Logic mới không còn so sánh string `AVAILABLE` trực tiếp. Thay vào đó dùng:

```text
AssetStatus.isEligibleForPledge()
```

Rule hiện tại:

```text
AVAILABLE -> eligibleForPledge = true
PLEDGED   -> eligibleForPledge = false
RELEASED  -> eligibleForPledge = true
SETTLED   -> eligibleForPledge = true
```

### Chuẩn hóa response API lookup tài sản

File đã sửa:

```text
backend/loan-onboarding/src/main/java/com/f88/loanonboarding/dto/response/asset/AssetLookupResponse.java
```

Response bổ sung:

```text
reasonMessage
```

Khi tài sản đang `PLEDGED`, API trả:

```text
assetState = PLEDGED
eligibleForPledge = false
reasonCode = ASSET_ALREADY_PLEDGED
reasonMessage = Tai san dang duoc cam co, khong the gan vao ho so vay moi.
```

UI có thể dùng `reasonCode` để mapping logic và dùng `reasonMessage` để hiển thị nhanh.
