## 2. Chuẩn bị backend gọi Camunda 8 SaaS Cluster

### Bối cảnh

Sau khi DMN được tạo trên Camunda Web Modeler, backend cần có khả năng gọi decision đã deploy trên cluster thay vì chỉ đọc file DMN local.

### Lỗi deploy DMN đã xử lý ở file local

Khi deploy/import DMN lên Camunda Web, gặp lỗi:

```text
Failed to parse DMN: org.camunda.bpm.model.dmn.DmnModelException: Unable to parse model
```

Nguyên nhân xử lý trong code:

```text
File DMN local có phần layout DMNDI/DC gây parser không tương thích.
```

Đã chuẩn hóa file:

```text
backend/loan-onboarding/src/main/resources/dmn/customer-age-eligibility.dmn
```

Thay đổi:

```text
Giữ lại decision table thuần.
Loại bỏ block DMNDI diagram/shape.
Decision id vẫn giữ là customerAgeEligibility.
```

### Dependency đã thêm

File:

```text
backend/loan-onboarding/pom.xml
```

Dependency:

```xml
<dependency>
    <groupId>io.camunda</groupId>
    <artifactId>camunda-client-java</artifactId>
    <version>8.9.11</version>
</dependency>
```

Mục đích:

```text
Cho phép backend gọi Camunda 8 SaaS Cluster để evaluate DMN decision đã deploy.
```

### Config đã thêm

File:

```text
backend/loan-onboarding/src/main/resources/application.properties
```

Đã thêm cấu hình:

```properties
app.camunda.dmn.mode=${APP_CAMUNDA_DMN_MODE:LOCAL}
app.camunda.dmn.customer-age-decision-id=${APP_CAMUNDA_CUSTOMER_AGE_DECISION_ID:customerAgeEligibility}

camunda.client.mode=${CAMUNDA_CLIENT_MODE:saas}
camunda.client.auth.client-id=${CAMUNDA_CLIENT_ID:}
camunda.client.auth.client-secret=${CAMUNDA_CLIENT_SECRET:}
camunda.client.cloud.cluster-id=${CAMUNDA_CLUSTER_ID:}
camunda.client.cloud.region=${CAMUNDA_REGION:}
```

Lưu ý:

```text
Không lưu client secret vào source code.
Khi chạy thật cần truyền bằng biến môi trường hoặc run configuration.
```

### DMN service đã cập nhật

File:

```text
backend/loan-onboarding/src/main/java/com/f88/loanonboarding/dmn/CustomerAgeDmnDecisionService.java
```

Logic mới:

```text
LOCAL mode:
- Load file dmn/customer-age-eligibility.dmn trong project.
- Evaluate bằng Camunda 7 embedded DMN engine.

SAAS mode:
- Gọi Camunda 8 cluster bằng CamundaClient.
- Evaluate decision theo decision id customerAgeEligibility.
- Parse decisionOutput để lấy eligible, reasonCode, reasonMessage.
```

Mục đích:

```text
Giữ backend chạy local ổn định khi chưa cấu hình Camunda SaaS.
Cho phép chuyển sang rule được quản lý trên Camunda Web khi cần test thật.
```
