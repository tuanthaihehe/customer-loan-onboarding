## 3. Sửa lỗi backend Docker không start do conflict dependency Camunda HttpClient

### Bối cảnh

Khi chạy backend bằng Docker, container `los-backend` fail với lỗi:

```text
An attempt was made to call a method that does not exist.
io.camunda.client.impl.http.HttpClientFactory.defaultClientBuilder
HttpAsyncClientBuilder.disableContentCompression()
```

Log cho thấy:

```text
camunda-client-java-8.9.11.jar đang gọi method disableContentCompression()
nhưng runtime lại dùng httpclient5-5.5.2.jar
```

### Nguyên nhân

`camunda-client-java:8.9.11` cần:

```text
org.apache.httpcomponents.client5:httpclient5:5.6.1
org.apache.httpcomponents.core5:httpcore5:5.4.2
```

Nhưng Spring Boot dependency management đang resolve:

```text
httpclient5:5.5.2
```

Version này không có method mà Camunda client gọi nên backend fail ngay lúc tạo `CamundaClient`.

### File đã cập nhật

File:

```text
backend/loan-onboarding/pom.xml
```

Đã thêm `dependencyManagement` để ghim đúng version tương thích với Camunda:

```xml
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.apache.httpcomponents.client5</groupId>
            <artifactId>httpclient5</artifactId>
            <version>5.6.1</version>
        </dependency>
        <dependency>
            <groupId>org.apache.httpcomponents.core5</groupId>
            <artifactId>httpcore5</artifactId>
            <version>5.4.2</version>
        </dependency>
    </dependencies>
</dependencyManagement>
```

### Kiểm tra dependency

Đã chạy:

```bash
mvn dependency:tree "-Dincludes=org.apache.httpcomponents.client5:httpclient5,org.apache.httpcomponents.core5:httpcore5,io.camunda:camunda-client-java"
```

Kết quả:

```text
io.camunda:camunda-client-java:jar:8.9.11:compile
+- org.apache.httpcomponents.core5:httpcore5:jar:5.4.2:compile
\- org.apache.httpcomponents.client5:httpclient5:jar:5.6.1:compile
```

### Kiểm tra compile

Đã chạy:

```bash
mvn compile
```

Kết quả:

```text
BUILD SUCCESS
```

### Lưu ý Docker

Cần rebuild lại Docker image backend để image mới đóng `httpclient5-5.6.1` thay vì image cũ đang có `httpclient5-5.5.2`.

Lệnh cần chạy:

```bash
docker compose build --no-cache backend
docker compose up -d
```
